# Maasai Mara Special Needs Animals Sanctuary

A responsive, single-page website for the Maasai Mara Special Needs Animals Sanctuary (Ngoswani, Narok, Kenya). Built with plain HTML, CSS and JavaScript — no build step required.

## Project structure

```
maasai-mara-sanctuary/
├── index.html      # Main page
├── css/
│   └── style.css   # Styles
├── js/
│   └── script.js   # Mobile menu, contact form, footer year
├── README.md
└── .gitignore
```

## Run locally

Open `index.html` in any browser.

## Live site (GitHub Pages)

Once published, the site is available at:
`https://YOUR-USERNAME.github.io/maasai-mara-sanctuary/`
